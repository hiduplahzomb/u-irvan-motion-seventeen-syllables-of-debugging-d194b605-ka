A haiku about debugging, in strict 5-7-5 form — the 3 AM production bug
that turns out to be a single typo on line 419.

```
Pager screams at three
production burns — one typo
fix line four-one-nine
```

`main.py` gates the entry (exactly 3 lines, syllable counts 5-7-5 by a
vowel-group counter) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`,
verifying the write byte-for-byte.
